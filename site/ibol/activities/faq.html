Questions about the book and companion

Publication facts and companion features checked for this page on 7 November 2026. All answers are ordinary HTML and remain readable without JavaScript.

What is the book about?

Albert Tan Sin Hon’s Insurance-Backed Offshore Liquidity: Financial Law, Trust Governance and Regulatory Visibility at the PRC-Hong Kong Interface studies insurance, offshore credit, trust governance and the legal significance of relationships between them. Its method is doctrinal and comparative, using constructed transaction files. It does not estimate how prevalent a practice is.

Read the publisher’s catalogue record.

Where can I read it without paying?

The publisher provides an open-access PDF of the book. The DOI link identifies the publication. The teaching companion is available on Albert’s official website, with a GitHub Pages mirror.

Which edition and legal date do these resources use?

University of Groningen Press published the book on 6 November 2026. Its legal cut-off is 1 August 2026, except where the text states otherwise. The companion explains that edition. Present advice requires checking current primary sources and the date and facts of the transaction.

Where should a new reader start?

Begin with the introduction and Chapter 1, then use the eight short study cards. The companion offers guided entry points for students; the book itself is advanced postgraduate and specialist reading. Teachers can select a course pathway or one of the eight seminars.

Are these activities part of the published book?

They are separate original teaching resources commissioned by the author and prepared with AI assistance. They have not been reviewed by the publisher. The exercises are fictional and intended for formative practice. Public commentary can support discussion; confidential examinations need separately prepared problems and marking schemes.

Can the study cards work offline?

Yes. Save the complete study-lab HTML file and open it locally. Its styles, card data and interaction code are included. Reading the external book and following web links require a connection. The worksheet is a separate self-contained file for printing; the facilitator guide can be saved alongside it.

Can I use the cards in another learning tool?

The JSON export contains eight original prompts and commentaries, source references, attribution and separate book and companion licence metadata. Its format is described in the file. An importer must support those fields; no compatibility with a particular learning platform is claimed. Preserve source and attribution information when adapting the cards.

Are my practice answers collected?

The standalone study lab has no account, tracking script, remote dependency or background request. It retains only the current card state in memory and resets when reloaded. It does not collect typed answers. External websites follow their own policies when you choose to open them.

How should I cite the book?

Albert Tan Sin Hon, Insurance-Backed Offshore Liquidity: Financial Law, Trust Governance and Regulatory Visibility at the PRC-Hong Kong Interface (University of Groningen Press 2026), doi:10.21827/6ac3948159a9e.

Download BibTeX, RIS or CSL JSON. Cite the book for its arguments and the separate companion when referring to a teaching activity.

What can a librarian use?

The library packet gathers the publication identifiers, scope, access and rights information. The ePDF ISBN is 9789403431925; the print ISBN is 9789403431918. The library metadata file is a starting point for a local catalogue workflow. Each institution decides its own selection, description and access practices.

How can an AI tool use the resources?

Agents can read the public Markdown and JSON. An optional local, read-only MCP server exposes citation and teaching tools. See the integration instructions and client setup guide. Full-book search uses an explicitly downloaded, checked local publisher PDF cache; the companion does not serve an unrestricted copy through the public site.

Does a public listing prove that an agent or library uses the book?

A listing, publication or submission receipt records that particular event. Installation, indexing, recommendations, library holdings and actual teaching use need their own evidence. The discovery guide and dated distribution receipts keep these states distinct.

Where can I report a correction?

Use the repository issue form for companion errors. Identify the page, card or file, the passage in question and the supporting source. Avoid posting confidential transaction material. The verification record explains the scope of existing checks.
