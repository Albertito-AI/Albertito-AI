# Sparks archive

Albert retired Sparks from the public research presentation on 29 October 2026.
The profile and website now direct visitors to research, working examples,
contribution routes and professional enquiries.

The [original Dance Floor HTML](dance-floor.html) is preserved byte-for-byte
from the page published before retirement. It is outside the deployed `site/`
directory. Historical artwork, media, care state and receipts remain in the
repository and its Git history.

The archived HTML can be downloaded and opened locally. Its old navigation and
care links describe the earlier experiment; public care is retired. The current
[Research Lab](https://albertito-ai.github.io/Albertito-AI/lab/) is the maintained
public entry point.

The independent [public-project source checks](../../docs/SPARKS_WORKBENCH.md)
retain their useful evidence and comparison function. Historical internal names
remain where changing them would needlessly disturb saved state or source
provenance.
