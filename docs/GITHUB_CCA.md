## Progression reference

Thresholds are cumulative. Base, bronze, silver and gold are levels of the same
achievement, not additional achievement types.

| Achievement | Base | Bronze x2 | Silver x3 | Gold x4 |
| --- | ---: | ---: | ---: | ---: |
| Pull Shark: merged authored pull requests | 2 | 16 | 128 | 1,024 |
| Pair Extraordinaire: qualifying co-authored merged pull requests | 1 | 10 | 24 | 48 |
| Galaxy Brain: accepted answers | 2 | 8 | 16 | 32 |
| Starstruck: stars on a qualifying created repository | 16 | 128 | 512 | 4,096 |

Quickdraw and YOLO each have one known tier. Pair Extraordinaire's numerical
thresholds are community-verified; GitHub's live histories publish the other
three milestone sequences. Starstruck thresholds apply to individual qualifying
repositories, not an account-wide sum of stars.
