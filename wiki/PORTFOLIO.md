# Project whitepapers

Twelve public papers prepared for Albert Tan Sin Hon with AI assistance, 2 November 2026. Each distinguishes inspected implementation from ideal future directions and identifies public-interest aims, risks and evidence gates. The private institutional paper remains in its private repository and is not mirrored here.

The links below open the versioned papers. Wiki publication is a separate state: see each repository’s `Publish project whitepaper to Wiki` workflow summary and `wiki/README.md`. All 12 public publishers reported `BLOCKED_UNINITIALISED` on 2 November 2026. The papers are committed, but the Wiki pages are not live yet.

To finish publication, use each **Initialise Wiki** link below. Create a page titled `Home`, enter a short welcome and save. GitHub then triggers the prepared publisher. It adds the whitepaper and preserves existing Home text. Check the workflow summary for `PUBLISHED`; a green job that says `BLOCKED_UNINITIALISED` is not a published page.
